# Prakriti Patel | Portfolio

A responsive dark-mode portfolio built with plain HTML, CSS and JavaScript.

## Features
- Responsive navbar with mobile menu
- Hero section with typing animation
- Skills and my R.C.T.F.C. prompt engineering method
- Project filtering with JavaScript
- Contact form with live validation and instant status message
