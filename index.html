My R.C.T.F.C. Prompt Method

  1. R

    Role

    Tell the AI who to act as, for example "Senior Web Developer".

  2. C

    Context

    Explain the situation, audience and goal so answers fit the real need.

  3. T

    Task

    State one clear, specific action. Avoid vague requests.

  4. F

    Format

    Define the output shape: code blocks, table, bullet list, word count.

  5. C

    Constraints

    Set the rules: tools allowed, limits, tone, and what to avoid.
